# Botanica

Статический демонстрационный каталог растений и флорариумов. Сайт работает без бэкенда и готов к публикации через GitHub Pages.

## Публикация

Загрузите содержимое этой папки в репозиторий GitHub. В настройках репозитория откройте **Pages**, выберите публикацию из ветки и корневой папки.

Все товары находятся в массиве `products` в файле `script.js`. Корзина, избранное, тема и демонстрационные заказы сохраняются локально в браузере.

Каталог содержит 50 захардкоженных товаров: 24 флорариума, 14 растений и 12 наборов. Работают категории, живые фильтры по цене и наличию, сортировка, поиск с подсказками, быстрый просмотр, избранное, управление количеством, расчёт доставки, формы обратной связи, демонстрационное оформление заказа, библиотека статей, мобильное меню и тёмная тема.
